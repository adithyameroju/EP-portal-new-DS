# Third-party skills registry

Compass agents may use skills beyond the ones in this repo (craft packs, house
styles, external playbooks). This file is the gate and the record for them.

## Policy (non-negotiable)

1. **Owner review is the only entrance.** A third-party skill may be used by
   Compass agents only after the owner has reviewed it and added a row below. An
   unlisted third-party skill is not approved — do not apply it.
2. **Craft, never control.** A third-party skill may add *feel* and craft
   guidance. It may **NEVER** override Compass tokens, components, or specs.
3. **On conflict, Compass supersedes — always.** If a third-party skill's guidance
   disagrees with a Compass token, component contract, spec, or the token audit,
   the Compass rule wins and the third-party guidance is ignored for that point.
   The token audit (0 errors) remains the only hard gate regardless of any skill.
4. **Every entry is recorded.** Each approved skill has a row capturing: name,
   source, version, scope of influence (what it's allowed to shape), and the
   review date. No row → not approved.

Note: the first-party **Compass Feel** pack (`skills-pack/compass-feel/`) is *not*
a third-party skill — it is distilled entirely from Compass specs and ships from
this repo. It also never overrides the system; it only restates ruled craft.
