# Compass

{/* Tagline: README.md lines 5-6, verbatim */}
Compass is Acko's enterprise design system — a single source of truth for every
color, spacing value, component, and interaction pattern used across Acko products.

{/* Stack line: README.md line 3 + package.json truth (Next 16, Base UI) */}
Built on **shadcn/ui v4 + Base UI + Tailwind CSS v4 + Next.js**, with
**Euclid Circular B** as the brand typeface.
