# Compass Storybook stories

This is the canonical home for all Storybook stories (decided S0.1, 2026-07-06):
**specs live in `.claude/specs/` (machine-read by Claude Code); stories live here**
(read by `.storybook/main.ts` via `../stories/**`).

The Storybook itself is built in **S2** of the GA roadmap (see
`.compass-build/PLAN.md`): Getting Started → Foundations (rendered from live
tokens) → Components (all 55, driven by `meta.ts`) → Patterns → the Compass SOP.
Until S2 lands, this folder intentionally contains no stories.
