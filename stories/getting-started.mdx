## The designer workflow (Figma → code)

{/* Steps: README.md "AI-assisted code generation" + .claude/skills/generate-code.md */}
1. **Load the skill** — `.claude/skills/generate-code.md` (Cursor or Claude Code reads it before generating).
2. **Provide a Figma frame URL** (via Figma MCP) or a screenshot.
3. **The AI generates a component** using only Compass tokens and `components/ui/` imports — it must analyze the frame, map every element to a Compass component, and surface every assumption in a "What I assumed" list.
4. **Run the audits** — `npm run audit` (0 errors required) and `npm run audit:compliance` (behavioral score).
5. **Log the build** — `npm run log` appends the "What I assumed" block to the drift ledger, which feeds the monthly tightening loop.

## Working with AI — how Compass constrains the LLM

{/* CLAUDE.md structure, stated factually */}
- `CLAUDE.md` is auto-loaded every session and overrides default behaviors.
- `.claude/specs/components/` — if a spec exists, the AI must follow it exactly.
- `components/ui/*.meta.ts` — machine-readable contracts (anti-patterns, AI hints, composition rules) with per-entry provenance; anything uncitable was omitted, never invented.
- The token audit blocks hardcoded hex, Tailwind color utilities, and arbitrary values at commit time.
- Read the "What I assumed" output on every build — that list is the drift-prevention mechanism.
